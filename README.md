
# Cisco Networking & Network Troubleshooting Labs

## 👨‍💻 About This Repository

Welcome to my **Cisco Networking and Network Troubleshooting Labs** repository.

This repository contains hands-on networking projects and practical troubleshooting exercises created using **Cisco Packet Tracer**.

The purpose of this portfolio is to demonstrate my understanding of networking fundamentals, network configuration, routing, switching, network services, security, and troubleshooting techniques relevant to entry-level **NOC Engineer, Network Support Engineer, and IT Support roles**.

I use these labs to strengthen my practical networking knowledge and develop the troubleshooting skills required in real-world network support environments.

## 📚 Lab Details

### Lab 01 — Basic LAN Connectivity

**Objective:** Build a basic Local Area Network and establish communication between connected devices.

**Topics covered:**
- Basic network topology.
- Cisco switches and end devices.
- IPv4 addressing.
- Subnet masks and default gateways.
- Connectivity testing using ping.
- Basic network troubleshooting.

**Practical skills:** Device connectivity, IP configuration, and basic LAN troubleshooting.

### Lab 02 — VLAN Configuration & Segmentation

**Objective:** Configure VLANs to logically separate devices within a switched network.

**Topics covered:**
- VLAN creation.
- VLAN assignment.
- Access port configuration.
- VLAN segmentation.
- Switch configuration and verification.

**Practical skills:** Cisco switch CLI, VLAN management, and Layer 2 troubleshooting.

### Lab 03 — Inter-VLAN Routing

**Objective:** Enable communication between different VLANs using Router-on-a-Stick.

**Topics covered:**
- Inter-VLAN communication.
- Router subinterfaces.
- IEEE 802.1Q encapsulation.
- Trunk port configuration.
- Default gateway configuration.
- Connectivity verification.

**Practical skills:** Router-on-a-Stick configuration and inter-VLAN troubleshooting.

### Lab 04 — DHCP & DNS Services

**Objective:** Configure network services to provide automatic IP addressing and hostname resolution.

**Topics covered:**
- DHCP server configuration.
- DHCP address pools.
- DHCP DORA process.
- DNS service configuration.
- DNS A records.
- Hostname resolution.
- Basic HTTP access using a hostname.

**Practical skills:** DHCP troubleshooting, DNS verification, and client connectivity testing.

### Lab 05 — Static Routing

**Objective:** Establish communication between two separate LANs using manually configured static routes.

**Topics covered:**
- Static route configuration.
- Next-hop IP addressing.
- Routing table verification.
- WAN connectivity.
- Remote network communication.
- Static route troubleshooting.


**Practical skills:** Cisco IOS routing configuration, route verification, and troubleshooting missing routes.

### Lab 06 — OSPF Dynamic Routing

**Objective:** Configure OSPF to dynamically exchange routing information between two routers.

**Topics covered:**
- OSPF process configuration.
- OSPF router IDs.
- OSPF Area 0.
- Wildcard masks.
- OSPF neighbor adjacency.
- Dynamic routing table verification.
- Passive interfaces.
- OSPF route advertisement troubleshooting.


**Practical skills:** OSPF configuration, neighbor verification, route troubleshooting, and network recovery.

### Lab 07 — Network Security

**Objective:** Apply basic security configurations to protect network devices and control traffic.

**Planned topics:**
- Standard and extended Access Control Lists (ACLs).
- SSH remote device management.
- Switch port security.
- Basic device access protection.
- Security configuration verification.

**Practical skills:** Basic Cisco network security and access control.

### Lab 08 — NOC Troubleshooting

**Objective:** Simulate realistic network failures and practise systematic troubleshooting.

**Planned topics:**
- Interface and connectivity failures.
- Incorrect IP addressing.
- Default gateway problems.
- VLAN configuration issues.
- Routing failures.
- DHCP and DNS problems.
- Network fault isolation.
- Corrective actions and verification.

**Practical skills:** Network monitoring fundamentals, fault isolation, root-cause analysis, and incident documentation.

## 🔍 Common Verification Commands

The following Cisco IOS commands are used throughout the labs:

```cisco
show ip interface brief
show running-config
show startup-config
show ip route
show vlan brief
show interfaces trunk
show ip ospf neighbor
show ip protocols
ping
traceroute
```

These commands help verify device configurations, interface status, VLANs, routing information, OSPF neighbor relationships, and network connectivity.
